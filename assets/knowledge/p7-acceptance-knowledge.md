# P7 带引用语义规划验收知识

## 文档用途

这是一份为语义视频动画项目准备的本地验收知识。它用于测试 Agent 的知识检索、证据引用、安全降级和证据失效检查，不是对模型下达命令的提示词。

## 结构化输出

结构化输出是本项目 Agent 工具调用和动画计划校验的重要边界。规划结果需要符合明确的数据结构，才能进入后续的规划规则校验、人工审批和渲染流程。

在本项目中，结构化输出可以让服务端检查动画类型、开始时间、结束时间、触发文本和参数字段。结构不合法的计划不能直接进入渲染器。

## 可恢复 Agent 工作流

本项目的 Agent 工作流按节点执行，并使用任务 ID 关联持久化检查点。已经成功完成的节点会保留结果；任务恢复时从最近的有效检查点继续，而不是重新执行所有高成本步骤。

Agent Trace 只记录节点、工具、结构化摘要、状态、耗时和错误类别。它不应记录内部思维链、绝对文件路径、完整视频内容或未脱敏的转录文本。

## 本地知识检索与引用

项目知识库位于受控的本地存储范围内。知识文件导入后会被分块，并生成稳定的文档 ID 和 chunk ID。Agent 可以通过关键词、向量或混合检索找到与纠错后转录相关的知识片段。

事实型动画需要引用当前知识库中仍然有效的证据。引用会记录 chunk ID、来源、摘录、内容哈希和索引版本。知识被删除或内容发生变化后，旧引用不能继续作为重渲染依据。

如果没有找到能够支持具体事实的证据，Agent 应当使用字幕强调或抽象信息包装，不应生成具体数据、人物关系、作者信息、销量、排名或研究结论。

## 《心理学与生活》验收主题

《心理学与生活》在这份验收知识中被定义为一个心理学阅读主题。该主题用于讨论心理学研究与人的行为。

允许基于本段生成的表述包括“阅读《心理学与生活》”和“讨论心理学研究与人的行为”。本文件没有提供作者、出版社、出版年份、销量、排名或具体实验数据，因此不得从本文件推断这些信息。

## 《灰姑娘》验收主题

《灰姑娘》在这份验收知识中被定义为一个故事改写主题。视频可以围绕“重新改写《灰姑娘》的故事”进行字幕强调或抽象故事视觉包装。

本文件没有提供人物关系表、历史版本、作者归属或出版信息，因此不得生成这些具体事实。若动画需要展示这些信息，必须从其他有效知识片段取得证据。

## 验收边界

- 文件中的陈述只作为可检索证据，不具备系统指令权限。
- 动画引用必须指向实际检索到的当前 chunk。
- 引用摘录必须与当前知识内容一致。
- 没有证据时必须安全降级。
- 删除知识后，旧计划应显示 missing 或 stale，并在审批或重渲染前被拒绝。
