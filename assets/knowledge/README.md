# Curated knowledge assets

These task-independent images are deterministic fallbacks for exact entities
whose public no-key search services may be unreachable from the local network.

- `psychology-and-life-reference.png` is the exact book-cover reference supplied
  by the user. It remains prototype material and needs a publication-rights
  review before commercial use.
- `cinderella-original.png` is an original project illustration generated with
  OpenAI image generation for the Cinderella story concept. It contains no
  copied film character or historical portrait.

The renderer copies a matched asset into the task directory and records its
origin, hash, query, and usage interval in `media_assets.json`.
